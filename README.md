# OpenGit

OpenGit is an interactive Git and GitHub visualization learning platform for students and Git beginners.

The project currently starts from the product plan in `OpenGit — 全局计划落地方案.md`. Engineering execution is tracked in `.context/`.

## Current Status

- Repository initialized.
- Project Context OS initialized in `.context/`.
- Implementation has not started yet.

## Next Step

Plan and scaffold the MVP: a Next.js 14 App Router application focused on the interactive playground, terminal simulation, Git state model, and first visualization views.

pnpm install
